### The World's Slowest Social Network 🌿

SnailGram is a fun, creative social-media-style website inspired by Instagram, but with one major difference — **everything happens at snail speed! 🐌**

This project was created as a **Useless Project / Fun Project** to experiment with frontend web development, UI design, and JavaScript interactions.

---

## 🌱 About the Project

Imagine a social network where:

- 🐌 Posts move at snail speed
- 🌿 Snails are your followers
- 📸 You can create posts
- 🎬 Watch slow "reels"
- 🗺️ Explore the garden
- 💬 Send snail messages
- ⏳ Everything takes its sweet time!

Welcome to **SnailGram — the social network where being slow is a feature, not a bug.**

---

## ✨ Features

- 🏠 Home Feed
